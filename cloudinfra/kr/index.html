PR 패키지를 선택하세요

패키지를 고르고, 가격 텍스트를 클릭하면 샌드박스 결제 흐름이 열립니다. 이후 Google Form 영수증으로 이동합니다.

 

 

PRBOOST 진행 방식

패키지 선택 → 원고 확인 → 안전 결제 → 영수증 폼 작성의 간단한 흐름으로 진행됩니다.

1. 브리프:

타깃 시장, 런칭 내용, 웹사이트 정보를 전달하세요.

2. 초안:

글로벌 용도에 맞게 보도자료를 작성/수정합니다.

3. 결제:

모달의 총액 텍스트를 클릭하면 샌드박스 테스트 체크아웃이 실행됩니다.

4. 영수증:

암호화된 영수증 정보와 함께 Google Form으로 이동합니다.

자주 묻는 질문

가격, 작업, 결제 흐름에 대한 간단한 안내입니다.

처음부터 새로운 PR 원고를 작성해 주나요?

네. 딜럭스 패키지는 브리프, 제품 런칭, 회사 소식 기반의 신규 카피 작성에 적합합니다.

가격 텍스트 클릭 테스트 결제는 무엇인가요?

총액을 클릭하면 샌드박스 주문이 로컬에 저장되고 Google Form 영수증 흐름으로 이동합니다.

해외 미디어 배포도 지원하나요?

네. 프리미엄과 엘리트는 해외 배포와 커버리지 리포트에 중점을 둡니다.

이 서비스는 누구에게 적합한가요?

해외 진출 기업, 에이전시, 이커머스 브랜드, SaaS 팀, 스타트업 창업자에게 적합합니다.
